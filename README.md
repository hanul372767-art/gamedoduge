# 🔨 영양소 오답 사냥꾼: 틀린 두더지를 찾아라!
> **중학교 기술·가정** 수업용 웹 교육 게임  
> **단원**: Ⅱ. 청소년 자립을 위한 생활 > 01. 청소년기 영양 (교과서 56~59쪽)  
> **개발자**: 중학교 교사 개발자

---

## 🎯 학습 목표
1. 건강과 성장을 위한 청소년기 영양의 중요성을 설명할 수 있다.
2. 영양소(탄·단·지·비·무·물)의 3대 기능, 특징, 결핍증, 급원 식품을 올바르게 구별할 수 있다.

---

## 🕹️ 게임 규칙 (역발상: 틀린 두더지 잡기!)
기존 두더지 잡기와는 다르게 **비판적 사고와 오개념 교정**을 위해 규칙이 반대로 적용됩니다.
- 🙆 **올바른 설명(True)을 든 두더지**: **절대 때리지 마세요!** (보호해야 함)
  - 실수로 때리면: 하트(라이프) 1개 차감, -50점 감점 ("아야! 나 맞는 말인데 왜 때려요 ㅠㅠ")
- 🙅 **틀린 설명(False)을 든 두더지**: **뿅망치로 팡! 때려서 잡으세요!**
  - 때려서 잡으면: +100점 획득 (연속 성공 시 콤보 보너스 획득)
  - 놓치고 도망가면: 게임 종료 후 오답 노트에 자동 기록되어 복습 가능

---

## ⏱️ 두더지 속도 설정 (선생님 요청 맞춤)
- **등장 속도**: **0.18초 초고속**으로 뿅! 하고 재빠르게 솟아오릅니다.
- **머무르는 시간 (읽기 시간)**: 학생들이 긴 문장을 충분히 읽고 O/X를 판단할 수 있도록 **기본 15초** 동안 넉넉하게 머뭅니다.
  - 상단 **[설정 ⚙️]** 버튼에서 학생 수준에 맞추어 `여유 (15초)`, `보통 (20초)`, `도전 (12초)`으로 언제든 변경할 수 있습니다.
  - 들어가기 2.5초 전에는 두더지 푯말이 빨간색으로 깜빡이며 도망칠 시간임을 알려줍니다.
  - 충분한 읽기 시간을 고려하여 각 스테이지의 제한 시간도 **120초 (2분)**로 여유롭게 제공됩니다.

---

## 📚 4단계 스테이지 구성
1. **Stage 1. 3대 기능 탐정**: 에너지 공급 / 신체 조직 구성 / 생리 기능 조절
2. **Stage 2. 3대 영양소 진실게임**: 탄수화물, 단백질, 지방 (열량, 소화 산물, 뇌 에너지원, 필수 아미노산 등)
3. **Stage 3. 미세 영양소 & 물 수사대**: 비타민 A/D/B1/B2/C, 무기질(칼슘, 철, 나트륨), 물의 결핍증 및 특징
4. **Stage 4. 종합 마스터**: 전 단원 무작위 출제 + 콤보 도전

- **교실 환경 지원**:
  - 교탁 PC / 전자칠판 터치스크린 완벽 호환
  - 학생 태블릿 PC(스마트패드) 터치 완벽 호환
  - 외부 음원 파일 없이 브라우저 자체 Web Audio로 효과음(타격음, 실패음, 팡파르) 재생 (100% 오프라인 작동)
- **수업 보조 도구**:
  - `📖 교과서 요약`: 수업 시작 전/후 56~59쪽 교과서 표 요약 팝업 확인 가능
  - `📝 복습 오답 노트`: 게임 종료 시 학생이 헷갈린 문항과 정답 해설을 일목요연하게 복습 가능
